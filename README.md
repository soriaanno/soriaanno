# 👨‍💻 Sobre mí

Soy desarrollador de software con formación en **Desarrollo de Aplicaciones Multiplataforma (DAM)** y el **Curso de Especialización en Desarrollo de Videojuegos y Realidad Virtual**.

Me apasiona desarrollar aplicaciones, crear videojuegos y escribir código limpio, escalable y mantenible. Disfruto aprendiendo nuevas tecnologías y afrontando retos que me permitan seguir creciendo como desarrollador.

Actualmente busco mi primera oportunidad profesional donde pueda aportar valor, aprender de un equipo experimentado y seguir evolucionando tanto a nivel técnico como personal.

- 📱 Desarrollando aplicaciones Android con **Kotlin** y **Java**.

- 💻 Mejorando mis conocimientos en arquitectura de software y buenas prácticas.
